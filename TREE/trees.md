Core terminology A tree is an acyclic, connected graph. It is structured around the following key components:Node: A structure containing a value or condition, or pointing to another node.
Root: The top node in a tree, which has no parent nodes.
Edge: The connecting link or line between two nodes.
Parent: A node that has an edge connecting downward to another node.
Child: A node successfully connected to another node when moving away from the root.
Leaf: A node with no children, residing at the bottom-most level of a tree branch.
Subtree: A tree structure formed by treating a child node as a root node itself.
Height: The number of edges on the longest downward path from a node to a leaf.
Depth: The number of edges from the root to a node.
